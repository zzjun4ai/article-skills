# Routing, Alignment, and Revision

Resolve five axes before drafting: task, paper type, section, language direction, and
target journal/audience. Use `submission-package` only for initial-submission materials.
Post-decision cover letters, rebuttals, and reviewer responses belong to
`article-response`; detailed availability work belongs to `article-data`.

For a complete section or major rewrite with ambiguous framing, show an alignment block
before prose:

- one-sentence manuscript argument;
- paragraph jobs and leading result;
- canonical terminology;
- primary reader and target journal/audience;
- inferred assumptions; and
- at most three high-leverage questions.

Skip the gate when claim, evidence, boundary, and requested section are already clear.
For short work, proceed directly.

When the user redirects a draft, preserve unaffected paragraphs verbatim. Change only
the flagged claim, paragraph, or order. If the correction changes the manuscript's core
argument, return to the alignment block before rewriting. Every proposed addition
triggers a deletion or replacement check so revision does not accumulate repetitive
main-text prose. Keep the terminology ledger stable unless the user explicitly changes
a canonical term.
