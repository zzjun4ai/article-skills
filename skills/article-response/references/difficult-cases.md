# Difficult response cases

- `infeasible experiment` — explain the concrete constraint, provide existing evidence,
  narrow the claim, add the limitation, and propose only work that is genuinely done or
  authorized.
- `conflicting reviewers` — preserve both comments, identify the conflict, follow any
  editor priority, and choose a manuscript change that does not falsely claim both
  incompatible requests were satisfied.
- `misunderstanding` — treat repeated misunderstanding as a manuscript clarity defect;
  revise the text even when the original statement was technically correct.
- `appeal-like` — separate factual/process errors from ordinary scientific disagreement.
  Do not draft accusations or an appeal without explicit user direction.
