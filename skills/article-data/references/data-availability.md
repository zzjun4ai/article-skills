# Data availability routing

Assign each dataset exactly one primary access route:

- `public-repository` — deposited with a stable URL or identifier.
- `controlled-access` — available through a named process with verified conditions.
- `within-article` — fully contained in article source data or supplements.
- `reused-public` — an existing public dataset with its own citation and identifier.
- `third-party-restricted` — controlled by another party; describe the verified route.
- `justified-request` — direct request is necessary because of a documented legal,
  ethical, commercial, or participant-privacy restriction.
- `not-applicable` — no new dataset supports the article; explain why.

For each dataset record `id`, description, supported outputs, route, location,
identifier, licence, restrictions, and deposit status. A planned repository or pending
accession must remain visibly pending. Never turn a placeholder into a completed fact.
